# Repository Growth Checklist

Use this before promoting a public repository.

- [ ] Clear one-sentence description
- [ ] Screenshot, GIF, or architecture diagram
- [ ] Fast installation instructions
- [ ] Example usage
- [ ] Tech stack listed
- [ ] Real use cases explained
- [ ] License included
- [ ] Issues enabled
- [ ] Discussions enabled where useful
- [ ] Good repository topics/tags
- [ ] Release created
- [ ] Contribution instructions
- [ ] Link back to profile / portfolio

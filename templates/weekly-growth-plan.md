# Weekly GitHub Growth Plan

## Monday
- Improve one public repository
- Publish one meaningful commit or release

## Tuesday
- Find 3 active open-source repositories in your stack
- Read issues and contribution guidelines

## Wednesday
- Submit 1 useful issue, docs fix, or PR

## Thursday
- Improve README, screenshots, examples, or tests

## Friday
- Publish a technical post linking to one repository

## Weekend
- Review stars, traffic, clones, issues, and referral sources
- Decide what to improve next week

Focus on quality and consistency, not artificial follower counts.
